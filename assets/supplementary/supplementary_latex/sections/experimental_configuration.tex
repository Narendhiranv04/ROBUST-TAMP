\noindent\textbf{Trial protocol.} Each variant runs ten trials with seeds 0--9, which set the pose perturbation of
Section~\ref{sec:supp-tasks}; the suite has 140 trials. Six trials run concurrently against one inference
server. A trial may make at most 11 FM calls (the initial request and ten replanning calls) and is stopped after
14{,}400\,s. A trial that ends because of an infrastructure failure (a server error or timeout, or a simulator
error) is excluded and rerun, at most twice; every other ending is scored. ICL runs execute only the five grill
variants, because kitchen prompts are identical in both conditions; their kitchen results are those of the
zero-shot run.

\noindent\textbf{Ablations.} Each condition changes one component of the full system. $-$Memory uses only the
current observation. $-$IF requests a correction for every newly visible object. $-$WHERE regenerates the
remaining plan instead of inserting corrective blocks and also suspends concurrent execution. Fixed front and
Fixed end insert every corrective block at the front or the end regardless of the planner's choice. $-$WHEN
suspends execution during inference. The LLM-planner condition runs the full system with Qwen3-8B with reasoning
enabled. Kitchen conditions are zero-shot and grill conditions use the ICL prompt.
